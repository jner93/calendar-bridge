# Calendar Bridge

Personal-use tool that keeps my iCloud calendar and Google Calendar in sync, in both directions.

## What it does

- Syncs my iCloud "JAR" calendar with my Google primary calendar every 15 minutes
- Matches events by iCal UID; creates, updates, and deletes propagate both ways
- Runs as a background daemon on my Mac mini (launchd)

## Why

My AI assistant can only read Google Calendar, so this bridge makes my iPhone's iCloud calendar visible to it.
